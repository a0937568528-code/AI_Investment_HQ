## 1. Purpose

本文件整理 AI 基礎建設供應鏈的重要公司，作為長期維護的公司研究資料庫。

本文件可供 Daily War Room、AI基本面追蹤框架、Event Update、Quarterly Review 引用；但不承載其流程、結論、投資組合或投資建議。所有公司內容以可追溯的公開資訊、公司揭露與後續研究更新為基礎。

## 2. Company Categories

| 類別 | 定義 | 主要研究問題 | 覆蓋公司 |
|---|---|---|---|
| GPU / AI Accelerator | 訓練與推論所需的通用或客製化加速器。 | 加速器需求、產品迭代、客製晶片與軟體生態如何演變？ | NVIDIA、AMD、Broadcom、Marvell |
| Memory | HBM、DRAM 與其他 AI 系統所需記憶體。 | 高頻寬與高容量記憶體的供需、良率與規格如何變化？ | Micron、SK hynix、Samsung |
| Foundry | 邏輯晶片製造與先進製程。 | 高效能運算晶片的製程供給與技術進度是否支持需求？ | TSMC |
| Packaging | 先進封裝與晶片／記憶體整合。 | CoWoS 等封裝能力是否影響 AI 系統交付與規格升級？ | TSMC |
| ABF | 高階 IC 載板與封裝連接。 | 高階運算內容量是否傳導至載板需求、規格與產能？ | 供應鏈研究保留區 |
| Networking | AI 叢集、資料中心與企業網路互連。 | 網路速度、埠數、架構與客戶資本支出如何驗證叢集擴張？ | Arista、Cisco、NVIDIA、Broadcom、Marvell |
| Optical | 高速光互連與資料中心傳輸。 | AI 叢集的頻寬與距離需求如何帶動光元件、模組與互連規格？ | 供應鏈研究保留區 |
| Server | 將加速器、記憶體、網通與電力整合為系統。 | AI 伺服器訂單、出貨、交期與系統架構如何演變？ | Dell、HPE |
| Cloud | 大規模雲端、平台與 AI 服務需求端。 | AI 服務採用、資本支出、資料中心與自研晶片如何連結？ | Microsoft、Amazon、Google、Meta、Oracle、OpenAI、Anthropic、xAI |
| Equipment | 半導體製程、檢測與量測設備。 | 客戶資本支出、先進節點與記憶體投資如何影響設備需求？ | ASML、Applied Materials、Lam Research、KLA |

## 4. Cross-company Relationships

以下關係用於建立研究上的供應鏈連結；實際供應關係、份額與時程須以各公司公開資料或可驗證證據確認。

```text
GPU / AI Accelerator
        ↓
HBM / DRAM
        ↓
Advanced Packaging（CoWoS）
        ↓
ABF Substrate
        ↓
AI Server
        ↓
Networking / Optical / Power
        ↓
CSP / Hyperscaler / AI Model Provider
```

| 關係 | 研究意義 |
|---|---|
| GPU／ASIC → HBM／DRAM | 加速器規格與出貨會影響高頻寬及系統記憶體的內容量與供需。 |
| GPU／ASIC + HBM → CoWoS | 晶片與記憶體整合會連結先進封裝的產能、良率與交付時程。 |
| CoWoS → ABF | 高階封裝後的晶片需透過載板完成封裝連接，供需傳導需分別驗證。 |
| 加速器／記憶體／封裝 → AI Server | 元件可得性、規格與成本共同影響系統出貨與部署時程。 |
| AI Server → Networking／Optical／Power | 叢集部署會提高高速互連、光傳輸、供電與散熱需求。 |
| CSP／Hyperscaler／AI Model Provider → 全供應鏈 | 服務需求、資本支出與資料中心建設決定基礎建設需求的需求端強度。 |
| Equipment → Foundry／Memory／Packaging | 設備訂單與出貨提供製程、記憶體與封裝投資的早期或同步觀察訊號。 |
