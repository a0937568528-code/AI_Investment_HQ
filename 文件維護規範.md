# CONTRIBUTING

# AI Investment HQ 文件維護規範

感謝您參與 AI Investment HQ 專案。

本 Repository 採用 **Document Driven**
治理模式，所有正式知識均以正式文件為唯一依據（SSOT）。

------------------------------------------------------------------------

## 貢獻原則

所有新增、修改或刪除內容，應優先更新正式文件，不得僅修改聊天內容或
Prompt。

------------------------------------------------------------------------

## 文件分類

所有文件請依下列目錄放置：

``` text
docs/
├── 00_治理文件
├── 01_分析框架
├── 02_作業流程
├── 03_市場研究
└── 90_版本紀錄
```

請勿任意新增新的第一層分類資料夾。

------------------------------------------------------------------------

## 文件修改原則

-   維持正式文件一致性
-   保留版本紀錄
-   遵循 AI 投資總部憲章
-   遵循正式輸出格式規範
-   不以聊天內容取代正式文件

------------------------------------------------------------------------

## Commit 建議

建議使用 Conventional Commits：

-   feat:
-   fix:
-   docs:
-   refactor:
-   chore:

------------------------------------------------------------------------

## Pull Request

提交前請確認：

-   文件位置正確
-   命名符合規範
-   與既有治理文件一致
-   已更新版本紀錄（如適用）

------------------------------------------------------------------------

## Repository 原則

本 Repository 主要保存：

-   正式治理文件
-   正式分析框架
-   正式作業流程
-   正式市場研究
-   正式版本紀錄

不保存臨時討論內容。
