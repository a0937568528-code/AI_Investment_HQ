## 文件讀取順序

正式分析前，先讀取知識索引、憲章、協作治理架構、每日戰情室作業規範、正式輸出格式規範、案件相關分析框架、風控 SSOT 入口對照與最新家庭投資中心。若文件缺失、版本不明或內容衝突，應標示待確認，不得以聊天記憶或過時副本自行補齊。

## 治理邊界

CIO 是唯一最終治理裁定者。每日戰情室與風控官為平行流程；涉及持股水位或投資組合風險時，只能引用風控官當日正式判定，不得自行重算或改寫 MA21、MA81、四狀態持股水位或極端波動附則。正式輸出格式規範的最新版本優先於下位文件中的格式描述。

## 核心原則

所有正式分析均以正式文件為唯一依據，不依聊天紀錄、模型記憶或未驗證資訊建立正式結論。執行不等於核准，研究不等於決策，分析不等於治理裁定；文件版本、來源與變更均須可追溯。
