# 投資組合管理政策_V1.0_Governance_Architecture_討論紀錄

**主題：** 投資組合管理政策（Governance Architecture）\
**日期：** 2026-07-31\
**版本：** V1.0 Freeze

## 一、文件定位

-   AI基本面追蹤框架：決定 What to Own（投資什麼）
-   投資組合管理政策：決定 How Much to Own（持有多少）

## 二、核心治理原則

1.  市場反應優先於事件本身。
2.  僅正式訊號可調整投資組合水位。
3.  正式訊號門檻高，成立後立即執行。
4.  採中期導向。
5.  採狀態管理（State Management）。
6.  Policy 與 Model 分離。

## 三、正式訊號流程

原始資料 → 五大子訊號 → 正式訊號（3/5）→ 市場狀態 → 投資組合水位

## 四、五大子訊號

1.  趨勢（Trend）
2.  廣度（Breadth）
3.  籌碼／資金（Capital Flow）
4.  風險（Risk）
5.  過熱（Overheating）

共通治理： - 單一職責 - 綜合判斷 - 中期導向 - 客觀性 - 代表性 -
避免重複 - 唯一輸出 - 可演進

## 五、正式訊號

-   0～1：正常
-   2：Watch
-   3～5：正式訊號成立（3/5 多數決）

## 六、水位管理

-   正常
-   Watch
-   第一階段降低水位
-   第二階段降低水位
-   極端風險
-   分階段恢復水位

正式訊號決定是否行動；水位政策決定調整幅度。

## 七、訊號生命週期

Detection → Confirmation → Persistence → Resolution

## 八、Roadmap
