# B模型｜「震盪盤跌型」候選失效案例：SOX、欣興

**記錄日期：2026-08-10**
**性質：候選失效型態，非普遍規律**

---

## 一、目前案例

**案例一：費城半導體指數（SOX）** — 2023～2024，B最大回撤-29.63% vs 買進持有-25.04%
**案例二：欣興（3037）** — 2023～2024，B最大回撤-38.54% vs 買進持有-36.43%

兩者皆出現「B回撤反而高於買進持有」的現象，且發生在同一時期、同一種行情結構。

---

## 二、共同結構比對

| 項目 | 欣興 | 費城半導體 |
|---|---|---|
| B模型最終資產 | 91.76萬 | 143.98萬 |
| 買進持有 | 123.35萬 | 199.12萬 |
| B最大回撤 | -38.54% | -29.63% |
| 買進持有最大回撤 | -36.43% | -25.04% |
| B相對劣勢 | -2.12個百分點 | -4.60個百分點 |
| 2023-2024切換次數 | 約70次 | 77次 |
| B最深回撤時點 | 2024-12-13（崩跌後） | 2024-12-30（崩跌後） |
| 買進持有最深回撤時點 | 2024-10-08（崩跌當下） | 2024-08-07（崩跌當下） |

兩者都不是「在急跌時判斷錯誤」，而是「急跌之後的反覆假訊號盤整期」把優勢磨掉——B的最深回撤都出現在市場真正的低點之後，不是低點當下。

---

## 三、候選失效型態定義

> **急跌 → 快速反彈 → 趨勢未真正確立 → 反覆穿越MA21／MA81 → 0%／80%頻繁切換 → 累積機會成本 → B回撤可能反而高於買進持有。**

典型切換模式（以欣興、SOX 2024年8-12月為例）：連續多次0%→80%→0%→80%的快速交替，市場一直給出「看似趨勢反轉」的訊號，但隨後又反向，並非模型判斷邏輯錯誤，而是市場本身沒有形成穩定趨勢。

---

## 四、重要限制：目前只是「候選」，不是「普遍規律」

**華邦電同期（2023-2024）測試相對表現良好**：B最大回撤-29.33% vs 買進持有-53.02%，回撤改善+23.70個百分點，是四段拆解中表現最好的一段，**沒有重現SOX/欣興的失效模式**。

因此不能說「半導體個股都會有這個問題」，更精確的說法是：

> **部分高波動科技／半導體標的，在特定的急跌—急彈—盤跌行情中，可能出現B模型的結構性弱勢；真正決定因素可能是個股自身的價格趨勢結構，而非產業類別。**

目前僅有2個案例，樣本數過小，不足以歸納為普遍規律。

---

## 五、B模型的兩種行情地圖

### 🟢 B最擅長：真正趨勢反轉
```
多頭 → 破壞 → 空頭 → 持續下跌
```
此時0%曝險很有價值。

### 🟡 B比較弱：急跌後未確立趨勢的反覆震盪
```
急跌 → 快速反彈 → 再跌 → 反彈 → 再跌 → 盤整
```
此時0%↔80%容易反覆被市場打臉。

---

## 六、治理原則（重要，維持既有紀律）

**目前不建議修改B模型：**
- 不為SOX加規則
- 不為欣興加規則
- 不重新最佳化MA21／81
- 不重新最佳化80%

先把這兩個案例記成「B模型『震盪盤跌型』候選失效案例：SOX、欣興」，作為模型適用環境地圖的一部分，與模型不利環境地圖並行保存，而不是只知道模型回測賺多少。
