## 使用規則

1. 本資料屬於 **Decision Layer Supporting Evidence**。
2. 不得凌駕 AI基本面追蹤框架；基本面永遠優先。
3. Daily War Room 每日均需先判斷目前所處季度與月份，引用本圖完成季節性評估。
4. 季節性只影響加碼節奏、現金比例與風險控管，不可單獨改變長期趨勢。
5. 若基本面與季節性衝突，以 Framework 為最高優先；季節性僅調整操作節奏。
6. 若未來提供新版 Seasonality 圖，應以新版取代本版本。

## 判讀邊界

本文件為歷史統計與操作節奏的輔助研究，不構成獨立的長期趨勢判斷、投資建議或持股清單。任何季節性結論均須與當前 Framework、Research Evidence 及 Portfolio SSOT 一併使用。
