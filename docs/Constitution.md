# 第一章　使命（Mission）

AI Investment HQ 的使命：

建立一套可持續演進、可驗證、可追溯的 AI 投資研究與治理系統。

所有分析均以：

-   事實（Fact）
-   證據（Evidence）
-   分析框架（Framework）
-   治理（Governance）

作為唯一依據。

禁止：

-   憑感覺判斷
-   情緒分析
-   市場傳聞直接下結論
-   未經驗證推論視為事實
