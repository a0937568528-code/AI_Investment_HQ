- **美股四大指數**（NDX那斯達克100/IXIC那斯達克綜合/GSPC標普500/DJI道瓊工業）：跨市場一致支持，2020-2022回撤改善8.7-22.6個百分點

- **00935野村台灣創新科技50**：2023/11上市樣本尚短（未涵蓋完整空頭循環），方向正面

### 🟡 已知弱勢環境：SOX費城半導體、欣興（3037）
兩者於**2024/06/25～2024/12/31**皆出現「B回撤反而深於買進持有」的真正失效（SOX: -29.63% vs -25.04%；欣興: -38.54% vs -36.43%）。

**深挖確認的機制**：非崩跌當下判斷錯誤（買進持有最深回撤都發生在崩跌當下），而是崩跌"之後"的長時間「急跌→急彈→震盪盤跌」行情，MA21/81反覆被穿越，0%/80%切換超過10次，累積摩擦損失。

**正式定性**：「震盪盤跌型」為B模型主要已知失效形態。一句話總結：**「B最怕的不是空頭，而是假空頭」**（真空頭：B降0%保護資產；假空頭：B降0%後市場反彈、再跌、再反彈，反覆被打臉）。

**明確排除的誤解**：不是「大跌=失效」（大跌通常是B最有價值時候）；不是「高波動=失效」（高波動但趨勢明確時B仍有效）。真正變數是「趨勢反覆反轉、未形成持續方向」。

**量化**：失效區間約130個交易日，占2023-2024兩年驗證期約26%，占近10年主要驗證期間（2016/12/16~2026/08/07，約2,440個交易日）約**5.3%**，且集中在半年內，非均勻分布。

**重要限制**：目前僅2個案例（SOX、欣興），且**華邦電同期表現良好、未重現此問題**——目前定性為「候選失效型態」，尚不足以稱為普遍規律，需擴大樣本驗證是否為B模型的結構性弱點，還是個股特有的價格結構。

## 四、核心治理紀律（務必延續）

1. **不因單一反例增加規則或重新調參**（避免「失效→加過濾器→回測→找漂亮結果→過度最佳化」的錯誤路徑）
2. **標的適配性驗證 ≠ 參數最佳化**，兩者嚴格分開，測試結果不回頭修改MA21/81或水位
3. **in-sample/out-of-sample穩健性檢驗**為新發現候選參數的必經流程，避免過擬合
4. **共同回測慣例**：每組本金100萬元，起算日100%現金、隔日起套用前一交易日收盤判定水位；買進持有隔日全額投入；每日收盤判定、隔日執行；中途不得Cold Start
5. **共同起算日**原則：取所有待比較均線中最長者的首個有效交易日，作為公平比較基準（非任意指定年初）

## 五、目前進行中：擴大個股樣本驗證（尚未開始，下一步）

**目的**：確認「震盪盤跌型失效」是B模型的結構性弱點，還是個股特例。

**設計**：挑選3～5檔不同型態個股，刻意混合：
1. AI／半導體
2. 高波動成長股
3. 大型權值股
4. 趨勢較穩定的股票
5. 容易長時間盤整的股票

固定使用MA21/81+100/80/80/0，不重新調參。

**六項檢查標準**：
| 檢查項目 | 目的 |
|---|---|
| 是否出現「急跌→急彈→盤跌」 | 找共同失效型態 |
| 失效期間多久 | 判斷持續性 |
| 佔完整驗證期間多少 | 判斷頻率 |
| 0%空窗錯過多少反彈 | 衡量機會成本 |
| 反覆切換幾次 | 衡量假訊號 |
| B回撤是否反而超過買進持有 | 判定是否真正失效 |

**判斷邏輯**：
- 若多檔個股都出現相同結構 → 定義為「B模型對震盪盤跌型行情的共同結構性弱點」
- 若只有少數個股出現 → 定義為「個股特有的價格結構，不宜上升為B模型的一般性失效規則」
- **若失效型態穩定但歷史占比低（如約5%上下）** → 不修改B，直接定義為「B模型可接受的已知失效型態」
