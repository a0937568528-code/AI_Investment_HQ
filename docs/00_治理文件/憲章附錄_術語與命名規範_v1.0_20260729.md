# Constitution 附錄｜術語與命名規範（Terminology & Naming Convention）

**適用文件：** Daily War Room、Night Dashboard、Research Report、Event Update，及未來新增之所有正式輸出文件
**維護原則：** 本附錄由 Claude 維護，作為跨文件術語統一標準；若內容與 Constitution 本文或其他正式治理文件有出入，**以 Constitution 為準**，並回報供本附錄修正
**版本：** v1.0｜取代先前「章節命名對照表_草案」

---

## 一、資料流總覽

```
框架分析
   │  （AI基本面追蹤框架三層判定，作為以下第①項輸入）
   ▼
五大框架評分
   │  （①AI基本面 ②估值 ③市場情緒 ④季節性 ⑤技術面，含主導因素判斷）
   ▼
框架檢核
   │  （是否觸發失效條件；是否屬估值修正/需求轉弱，依附於框架分析結果）
   ▼
決策層
   │  （整合框架分析＋籌碼＋季節性＋評價，形成投資判斷）
   ▼
行動層
   │  （✅加碼／⚠️減碼／⏸️續抱／👀觀望，不得與決策層相反）
   ▼
官方儀表板
   （所有燈號、框架健康度、市場情緒、長短線觀點彙總）
```

**核心原則：** 上游結論是下游的輸入，下游不得推翻上游判斷（例如行動層不得與決策層相反、決策層不得與框架分析矛盾）。

## 二、名詞定義表

| 統一名稱 | 涵蓋範圍 | 輸出給誰 |
|---|---|---|
| **框架分析** | 僅AI基本面框架本身：第一層(領先)/第二層(供應鏈)/第三層(驗證) | 五大框架評分 |
| **五大框架評分** | ①AI基本面 ②估值 ③市場情緒 ④季節性 ⑤技術面，並給出主導因素 | 框架檢核 |
| **框架檢核** | 是否觸發第一/二層失效條件；是否屬估值修正/需求轉弱 | 決策層 |
| **決策層** | 整合框架分析＋籌碼＋季節性＋評價，形成投資判斷 | 行動層 |
| **行動層** | Action Layer固定格式：✅加碼／⚠️減碼／⏸️續抱／👀觀望 | 官方儀表板 |
| **官方儀表板** | 所有燈號、框架健康度、市場情緒、短中長線觀點彙總 | （最終呈現層，無下游） |

## 四、使用規則

1. 新增任何文件類型（週報、季度回顧等）時，優先沿用本表既有名稱，不另創新詞彙
2. 若GE、GPT或Claude之輸出使用了非本表定義的名稱指稱同一概念，應於下次修訂時統一改用本表名稱
3. 「框架分析」與「五大框架評分」不可混用——前者是單一框架（AI基本面追蹤框架）的內部三層判定，後者是跨五個維度的綜合評分，兩者為輸入/輸出關係而非同義詞
