# 風控輔助腳本說明：TWII／SOX 缺口均線候選判斷

**建立日期：** 2026-08-06
**性質：** 工具說明文件（非正式治理文件，不具SSOT效力）
**用途：** 記錄以下腳本之功能、資料流向與治理定位，避免未來對其角色產生誤解

---

## 一、緣起

原始需求為費半指數(SOX)之缺口/均線監控，因**XQ無法將費半資料匯出為Excel**，故改採yfinance套件直接向Yahoo Finance抓取資料，繞開XQ的匯出限制。台股加權指數(TWII)之候選判斷腳本，是同一次作業中一併完成，並非獨立於SOX之外的另一件事——兩者共用同一套缺口/均線計算邏輯，只是套用在不同標的上。

## 二、腳本清單

| 檔案 | 功能 |
|---|---|
| `update_tw.py` | 透過yfinance下載台股加權指數(^TWII)歷史日K，存至 `D:\AI_Investment_HQ\data\tw_market\TWII.csv` |
| `calc_twii_gap_ma.py` | 讀取上述TWII.csv，依《風險優先模型_v1.0.2_正式規格書》第4、8節缺口/均線定義，逐日計算「候選判斷」，輸出 `TWII_缺口均線候選判斷表.csv` |
| `update_market_data.py` | 透過yfinance下載費半指數(^SOX)歷史日K，並套用相同缺口/均線定義，輸出 `SOX_費半_近半年缺口均線追蹤表.csv` |
| `更新台股資料.bat`／`更新台股並計算缺口.bat`／`計算台股缺口均線.bat`／`更新美股資料.bat` | 對應上述腳本之執行捷徑 |

## 三、治理定位（重要）

**兩者皆為「候選判斷／輔助觀察」性質，不是正式水位判定來源：**

- **TWII候選判斷表**：僅供風控師人工判斷時參考比對、或供Claude事後做規格一致性核對之輔助依據。依2026/08/04 CIO核可之工作流程，正式《每日執行紀錄》仍須由風控師先完成人工判斷，Claude僅做規格書一致性核對，本腳本輸出不自動、也不應直接寫入正式紀錄。
- **SOX追蹤表**：純屬Core Layer輔助觀察指標，資料來源與計算結果**不影響、不觸發**Risk First Model之水位動作。Risk First Model水位判斷唯一依據為台股加權指數(TAIEX)，與SOX追蹤表完全分開，不可混用。

## 四、已知技術限制

`calc_twii_gap_ma.py` 之候選State計算採簡化近似：均線空方確認觸發時，無論目前State為何，一律至少跳至State2（`state = min(max(state, 2), 3)`），未逐階核對是否已先由第一個反向缺口進入State1。此為腳本自行揭露之已知簡化，正式判斷仍須風控師依規格書逐步核對，不可直接採用候選State數字。

## 五、與正式規格之關係

本說明文件不修改、不補充《風險優先模型_v1.0.2_正式規格書》任何條文，僅記錄工具用途與定位，避免候選判斷表與正式《逐日事件與水位》紀錄檔混淆。
