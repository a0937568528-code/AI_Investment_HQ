## 1. 模型目的

在基本面未被推翻的前提下，利用市場結構（缺口、均線）管理機動倉位，降低最大回撤（Maximum Drawdown）。

本模型不預測市場、不追求最佳買賣點、不追求最大報酬。唯一目標是控制風險、降低回撤。

---

## 2. 適用範圍

- 標的：台股加權指數（TAIEX）相關部位。
- 方向：僅做多（Long Only）。
- 管理對象：總部位中「機動倉」的部分（見第5、6節）；核心倉不受本模型管理。
- 前提：本模型須與第一層（Core Layer，基本面判斷）搭配使用，第一層判斷未通過時，本模型不生效。

---

## 3. 核心理念

1. **Risk First（風險優先於報酬）**：控制風險優先於追求報酬；減碼速度快於回補速度；空方確認門檻低於多方確認門檻。
2. **快出、慢進**：下跌時寧可提早減碼、少賺一段，也不等所有訊號都確認才行動；上漲時寧可慢一點回補、少賺一段，也不因單一次反彈就重新滿倉。
3. **事件驅動（Event Driven），非預測模型（Prediction Model）**：模型不嘗試預測市場，只在市場提供新的離散事件證據後，依既定狀態機調整機動倉位。狀態沒有時間上限，橫盤本身不是事件、不改變狀態。
4. **模型設計規範**：任何規則的觸發條件，若在同一趨勢中可被無限次重複觸發（持續狀態，如「收盤持續在某均線之下」），不得納入本模型。觸發條件必須是離散事件（缺口出現、均線確認、缺口回補），每次只觸發一次狀態轉移。

---

## 4. 名詞定義

| 名詞 | 定義 |
|---|---|
| 向上缺口 | 當日最低價 > 前一日最高價 |
| 向下缺口 | 當日最高價 < 前一日最低價 |
| 缺口回補（收盤確認制） | 向上缺口：收盤價 ≤ 缺口下緣（即形成缺口當日的前一日最高價）；向下缺口：收盤價 ≥ 缺口上緣（即形成缺口當日的前一日最低價）。盤中觸及不算，僅以收盤價判定 |
| 均線確認 | 以收盤價為準；空方確認＝收盤價同時低於MA10與MA20；多方確認＝收盤價同時高於MA10與MA20 |
| 核心倉 | 總部位中固定不動的部分，僅由第一層（基本面）決定是否調整，技術面不影響 |
| 機動倉 | 總部位中由本模型（第二層）管理的部分 |
| 追蹤缺口 | 目前狀態機正在追蹤、尚未回補的缺口（多方、空方各自獨立追蹤） |
| 離散事件 | 只在特定時點觸發一次的訊號（缺口出現、均線確認、缺口回補），觸發後不會因狀態持續而重複觸發 |

---

## 5. 第一層：Core Layer（核心倉）

**唯一判斷問題：基本面是否被推翻？**

- **否** → 永遠保留50%核心持股，技術面再差也不會因第二層模型將其賣出。
- **是** → 重新評估投資假設，此後決策不屬於第二層模型管轄範圍。

---

## 6. 第二層：Water Level Layer（水位管理）

**前提：基本面尚未被推翻**（即第一層判斷為「否」）。

- 只管理另外50%的機動倉（機動倉自身0～100%的刻度，對應總部位0～50%）。
- 所有減碼與回補只作用於機動倉，不影響核心倉。

---

## 7. 狀態機

模型為離散狀態的事件驅動狀態機，共4個水位狀態：
State 0：總持股100%（核心50%＋機動50%，滿倉）
State 1：總持股80%（核心50%＋機動30%，第一次減碼）
State 2：總持股60%（核心50%＋機動10%，第二次減碼）
State 3：總持股50%（核心50%＋機動0%，第三次減碼）

狀態轉移只由第8節定義的離散事件觸發，無時間上限，橫盤不改變狀態。

**轉折觀察期分支邏輯（OR，非AND）**：
第一個反向缺口 → 進入轉折觀察期（狀態轉移一階）
│
┌─────┴─────┐
▼ ▼
缺口回補 均線確認 或 第二個同向缺口
│ │
▼ ▼
回到原趨勢 新趨勢確認（狀態再轉移一階）

---

## 8. 事件定義

| 事件 | 定義 |
|---|---|
| 第一個反向缺口 | 目前追蹤方向（多／空）尚未有追蹤中缺口時，出現的第一個該方向缺口 |
| 第二個（以上）同向缺口 | 目前已有追蹤中的同方向缺口時，再次出現同方向缺口（覆蓋原追蹤目標） |
| 第三個同向缺口 | 已完成前兩階段減碼（第二次減碼狀態下），同一波追蹤中再出現第三個同方向空方缺口 |
| 均線確認 | 收盤價同時站上／跌破MA10與MA20 |
| 缺口回補 | 追蹤中的缺口以收盤確認制完成回補（見第4節） |

---

## 9. 減碼規則（快出）

| 階段 | 總持股變化 | 觸發事件 |
|---|---|---|
| 第一次減碼 | 100%→80% | 第一個反向（空方）缺口 |
| 第二次減碼 | 80%→60% | 均線空方確認 **或** 第二個同向（空方）缺口 |
| 第三次減碼 | 60%→50% | 第三個同向（空方）缺口 |

- 每次減碼固定降低總持股20個百分點，全數由機動倉扣除，核心倉不受影響。
- 減碼不需等待確認，第一個反向缺口出現即刻執行（快出）。

---

## 10. 回補規則（慢進）

回補採**逐階棘輪式**，每次事件只回補一階，不得跳階：

| 階段 | 總持股變化 | 觸發事件 |
|---|---|---|
| 第一次回補 | 50%→60% | 均線多方確認 或 第二個同向（多方）缺口（若在第三階） |
| 第二次回補 | 60%→80% | 均線多方確認 或 第二個同向（多方）缺口 |
| 第三次回補 | 80%→100% | 均線多方確認 或 第二個同向（多方）缺口 |

- 第一個多方反向缺口出現時，僅進入觀察期，**不改變水位**（不對稱設計：多方第一階段只觀察，不急於加回）。
- 追蹤中的空方缺口完成收盤回補（趨勢失敗）時，水位回升一階（棘輪式），非直接跳回滿倉。

## 11. 完整SOP（每日執行流程）

**0. 資料來源查證（v1.0.2新增，每次判定前強制執行，不得省略）：**

在進行任何一次每日判定（含首次判定、當日重新判定、跨對話視窗延續判定）之前，須先明確查證下列兩項資料來源之最新狀態，不得依對話記憶或預設值直接推導：

a. 查證《風險優先模型正式規格書》現行版本之基準值定義（如第4節缺口回補判定基準之計算方式）

b. 查證最新一筆《逐日事件與水位追蹤資料》（CSV），確認查證當下「最近一個交易日」之：
   - 水位階段（State）
   - 總持股比例
   - 是否有追蹤中缺口（含觀察期狀態）

若判定過程中發現a、b任一項未經查證即產出結論，須主動重新查證後更正，並於結論中註明「已重新查證資料來源」。

1. 取得當日OHLC與MA10、MA20（收盤價計算之簡單移動平均）。
2. 檢查是否形成新缺口（向上／向下），依第8節判定為第一個或第二個（以上）同向缺口。
3. 若形成新的反向缺口：依第9節執行對應階段的減碼。
4. 若形成新的同向缺口（多方，且目前水位<100%）：依第10節執行對應階段的回補判斷。
5. 檢查當日均線確認條件（多方／空方），依第9、10節執行對應的減碼或回補。
6. 檢查追蹤中的缺口是否以收盤確認制完成回補：
   - 空方缺口回補 → 水位回升一階（趨勢失敗，重置該方向追蹤）。
   - 多方缺口回補 → 僅重置該方向追蹤，不影響水位。

   **6.1 追蹤中缺口揭露（v1.0.1新增，v1.0.3補充用語澄清，每日固定揭露，不得省略）：**
若目前有任一方向（多／空）之缺口正處於追蹤中（含觀察期），每日判定結論須明確列出：
- 缺口方向（多方／空方）
- 缺口形成日期
- **缺口回補判定基準值**（依方向不同，非對稱）：
  - 多方缺口回補基準＝**缺口下緣**（形成日前一日最高價）
  - 空方缺口回補基準＝**缺口上緣**（形成日前一日最低價）
- 目前狀態（是否處於觀察期，或依下方「盤整中」定義標示）
- 下一個可能觸發之事件與對應水位變化（回補條件 vs. 確認條件／第二同向缺口條件，二擇一以上列出）

不得以「仍需依模型目前追蹤中的缺口狀態判定」等模糊語句帶過；未實際列出上述五項視為判定不完整。

**「盤整中」用語定義（v1.0.3新增）：** 若追蹤中缺口尚未以收盤價完成回補，且當日均線狀態已從多方／空方確認退回中性（即收盤價未同時高於或同時低於MA10與MA20），此組合狀態應標示為「盤整中」。「盤整中」僅為狀態描述用語，不構成新的觸發事件，不改變水位、不影響缺口追蹤邏輯本身——依第3節模型設計規範，均線退回中性不是離散事件，不觸發任何狀態轉移。

7. 更新當日水位、當日總持股比例、機動倉狀態，記錄觸發事件。
8. 重複第0～7步，逐日執行，無需人工判斷是否「盤整過久該重新評估」。

## 12. 例外處理

### 12.1 模型首次導入（Cold Start）

- 若使用者已持股一段時間、經歷過模型未介入的漲跌，才開始導入本模型：**不追認導入前已發生的舊訊號**。
- 從決定導入模型的當下，視為全新循環起點，完全依第11節SOP往後執行；不回頭將導入前錯過的訊號一次性補做到當下應有水位。
- 導入時應記錄明確的「起點日期」，該日期之前的部位狀態視為既定事實，不用模型規則回溯評價或修正。

### 12.2 第一層與第二層的優先順序

- 第一層（基本面是否被推翻）永遠優先於第二層。若第一層判斷基本面已被推翻，第二層模型立即停止適用，需重新評估投資假設。

## 13. 模型限制

1. **驗證樣本有限**：本模型正式規則的驗證基礎為一段延長多頭樣本（301個交易日，2025/05/13～2026/08/04）與一段空頭樣本（301個交易日，2021/09/06～2022/11/24），均為台股加權指數。尚未驗證於：長期大幅震盪、金融危機式急殺、或非台股市場。
2. **僅適用於與加權指數連動性高的部位**：本模型的缺口、均線訊號均以加權指數計算。若實際持有部位（個股、槓桿商品等）與大盤指數連動性不高，模型訊號不必然適用於實際部位的風險狀況，應另行評估。
3. **不含籌碼面、消息面判斷**：本模型僅依技術結構（缺口、均線）運作，不納入外資買賣超、基本面消息等因素；籌碼面/消息面判斷屬於第一層（Core Layer）或人工判斷範疇。
4. **島狀翻轉等型態未納入**：因加權指數缺乏可靠的還原全值資料，島狀翻轉等型態目前列為未來研究項目，不在本模型正式規則內。
5. **新證據出現前，本文件為唯一正式規格**：未來若有新市場型態的回測資料，應重新驗證後再修訂本文件版本（v1.1、v2.0等），修訂前以本版本為準。
